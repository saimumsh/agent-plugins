# Stack detection (follow what exists; never add a second way)
| Look at | Learn |
|---|---|
| `package.json` deps/scripts, lockfile | framework (React/Next, Vue/Nuxt, Svelte/Kit, Angular, Solid), package manager, scripts |
| `tsconfig.json` | TypeScript strictness, path aliases |
| router files / `app/` / `pages/` | routing style |
| store files | state (Redux/RTK, Zustand, Pinia, signals, TanStack Query/SWR for server state) |
| styling config | Tailwind config ↔ design tokens, CSS modules, styled-components, vanilla-extract |
| test config | Vitest/Jest, Testing Library, MSW, Playwright/Cypress, jest-axe/vitest-axe |
| API client | OpenAPI generator (orval, openapi-typescript, openapi-generator) and its output folder |
| analytics | the wrapper module events must go through |
| existing similar feature | the pattern to copy |
Record the result in your journal once per repo; reuse it next time.
