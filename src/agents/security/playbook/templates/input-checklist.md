# Input checklist
- [ ] Architecture Document: components, data flows, trust boundaries, external integrations, data model with PII classification, deployment, authn/authz design
- [ ] Release Candidate: tag/commit, build, **test environment URL** (in scope; not production), release notes (new components, flows, fixed SEC findings), two+ test accounts with different roles
- [ ] Compliance Obligations: list of regimes/contracts/policies that apply, data types covered, regions, required controls and evidence
- [ ] Previous threat model, open findings, risk acceptances (with expiry)
Anything not matching the RC (old architecture version, wrong commit) counts as missing.
