# Input checklist
- [ ] Data Model: every entity, attribute (logical type), relationship and cardinality; PII classification; retention
- [ ] Requirements: data volumes and growth, read/write throughput, latency targets, availability/RPO/RTO, retention, deletion rights, residency, audit needs
- [ ] Technical Standards: engine (and its ADR), naming, keys, encryption, PII handling, migration rules, backup expectations
- [ ] Optional: Architecture Document (runtime flows), API Contracts (query patterns), existing schema + migrations
Record an assumption for every gap; volume assumptions must be explicit numbers.
